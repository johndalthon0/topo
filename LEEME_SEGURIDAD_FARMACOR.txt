FARMACOR - PROTECCIÓN DE BASE DE DATOS + NOTIFICACIONES + BLOCKCHAIN
===================================================================

ESTA ACTUALIZACIÓN NO AGREGA NINGÚN PAQUETE NPM NUEVO.
Si tu Angular ya funciona, NO necesitas ejecutar npm install por esta función.

QUÉ HACE TODO JUNTO
-------------------
1. Django marca sus conexiones MySQL como autorizadas.
2. Un solo comando instala protección en todas las tablas críticas existentes.
3. INSERT / UPDATE / DELETE directos desde phpMyAdmin, Workbench o consola MySQL se bloquean.
4. El dato original NO se modifica.
5. El intento se conserva en la tabla seguridad_intentos_bd.
6. FARMACOR muestra una campana 🔔 con el número de intentos no revisados.
7. La pantalla Notificaciones muestra fecha, tabla, registro, usuario BD y acción bloqueada.
8. En compras y ventas, al abrir el detalle, FARMACOR intenta comprobar el hash asociado contra Blockchain si Ganache y el servicio Node están activos.

INSTALACIÓN EN UN SOLO PASO
---------------------------
Con MySQL encendido, haz doble clic en:

    INSTALAR_SEGURIDAD_FARMACOR.bat

o desde backend:

    python manage.py instalar_seguridad_bd

No se requiere una migración nueva para la tabla de auditoría.

PRUEBA
------
1. Inicia Django y Angular como siempre.
2. En phpMyAdmin > farmacia_db > SQL usa un ID REAL, por ejemplo:

   UPDATE ventas_venta SET total = 1 WHERE id = 1;

3. MySQL debe responder:
   FARMACOR: operación directa no autorizada. Cambio bloqueado.

4. La venta conserva su valor original.
5. En FARMACOR aumenta la campana 🔔.
6. Abre Notificaciones para ver el intento.

IMPORTANTE
----------
El bloqueo físico del cambio lo realiza MySQL mediante triggers.
Blockchain conserva/verifica la evidencia criptográfica de operaciones críticas.
FARMACOR avisa al administrador mediante Notificaciones.

MODO MANTENIMIENTO
------------------
Para retirar temporalmente los triggers:
    DESINSTALAR_SEGURIDAD_FARMACOR.bat

Para volver a instalarlos:
    INSTALAR_SEGURIDAD_FARMACOR.bat
